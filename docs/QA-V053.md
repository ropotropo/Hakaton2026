# v0.5.3 — Separation and inspection cameras

Sole game author: Mykyta Borisov. 15 November 2026.

The launch renderer now uses a 4.7 s presentation shot after an observed manual
stage release. It follows the actual released object's center, combines static
hardware envelopes for framing, eases into a nose/aft angle and returns to chase.
The shot uses no mission-progress timer and changes no forces or controls.

A restored or initially released stage does not spawn a fresh separation or
camera beat. Low-altitude and reduced-motion guards skip the shot. Pausing
freezes its presentation clock; manual inspection cancels it. External return
from inspection eases offsets over 0.48 s, retaining the ground clamp. Mounted
cockpit/descent poses and handoffs between different physical frames stay exact.

121 automated tests pass, including event eligibility, held-checkpoint release,
restore/discontinuity guards, pause, reduced motion and combined body framing at
phone aspect ratios. Production and portable HTML builds pass. The previous
v0.5.1–0.5.2 checks and model limits remain in QA-V051.md.

Browser verification uses a checkpoint saved through the normal interface after
an actual 1× practice ascent reached core depletion at T+154 s / approximately
72 km. Restore this checkpoint, release the core manually and observe the shot
and its automatic return; then check inspection and mounted camera behavior.
